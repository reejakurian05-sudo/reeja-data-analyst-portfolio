# Enterprise Performance & KPI Analytics

## Business Problem
Organizations across insurance, finance, and operations lacked a unified,
trusted view of performance KPIs due to siloed data sources and manual reporting.

## Objective
- Build automated KPI reporting
- Improve data accuracy and consistency
- Enable leadership-level decision-making
- Reduce manual reporting effort

## Tools Used
- SQL Server
- Power BI
- DAX
- SSRS
- Advanced Excel
